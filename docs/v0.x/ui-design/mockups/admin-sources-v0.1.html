起動オプション(手動起動のみ)
削除の割合ルール・最小件数ルールを無視して削除します。

次のようになります

  • 削除対象が割合のしきい値を超えていても削除されます。
  • TTL が経過した文書だけが対象です。経過していない文書は消えません。
  • 削除された文書は検索から消え、元に戻せません。
確認にチェックすると起動できます。

起動オプション(手動起動のみ)

実行前に確認してください

  • 全文書を書き直すため、時間がかかります。削除の判断には影響しません。
