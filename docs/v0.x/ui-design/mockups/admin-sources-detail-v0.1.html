ダイアログ: 孤児ロックの解放(DLG-5。要確認・警告つき。承認済み(ゲート C))

ロックを解放しますか

データソース demo-handbook に、動いているジョブのないロックが残っています。

解放すると次のようになります

  • ロックだけが消えます。対応するジョブはないため、ジョブの状態は変わりません。
  • ジョブは起動されません。解放後にクロールを起動してください。
確認にチェックすると解放できます。

解放できない場合(リース期限内の実行中・実行待ち、取得直後)は 409 の理由を、ダイアログ内のアラート(消えない)で示す: 「解放できませんでした: ジョブが実行中です。取消を使ってください」など。リース切れのジョブのロックでは、解放するとジョブが「失敗(ロック解放済み)」になる旨を警告枠に書く(J2 のダイアログ見本を参照)。

データソース登録

データソースを登録

基本

半角英数字で始まり、半角英数字と . _ - が使えます(256 文字まで)。登録後は変更できません。
登録後は変更できません。

取得設定

Crawler のコンテナから見たパス。保存時に接続の確認はしません。接続できない場合は、クロールを起動したときにジョブが失敗します。

実行周期

分 時 日 月 曜日の 5 項目を空白 1 つで区切ります(例: 0 3 * * * は毎日 3:00)。空にすると手動のみで実行します。この cron は Asia/Tokyo(Crawler の設定)で解釈されます。

削除の判断

日
最後に見つかった日時(存在確認日時)からこの日数を過ぎた文書が、削除の対象になります。1 以上の整数。
%
削除対象が、削除前の登録文書数のこの割合を超えると、そのクロールでは削除しません。0 以上 100 未満。
件
削除対象がこの件数以下なら、割合に関わらず削除します。0 以上の整数。

検証エラー(送信時。クライアントの範囲検証+サーバーが返した項目別エラー)

上部に件数付きのエラー要約(項目へのリンク付き)を出し、フォーカスを移す。サーバー(Crawler)が返した項目別のエラー(既に登録済みの識別子、cron の形式、取得設定)も同じ形で項目の下に出す。
