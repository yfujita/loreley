取消(DLG-3。要確認・標準)— 実行中のジョブ

ジョブを取消しますか

実行中のジョブ job-0002-demo(データソース demo-shared-docs)の取消を要求します。

実行中のジョブは、取消要求が受け付けられた後、次の確認点で止まります。完了は、ジョブの状態で確認してください。実行待ちのジョブは、すぐに取消されます。

取消済み(job_already_finished)だった場合は成功として扱い、終了済みの状態を示す(スナックバー「ジョブはすでに終了しています(状態: 成功)」)。

再実行(DLG-4。要確認・警告つき。元の指定を読み取り専用で提示。承認済み(ゲート C。#5))

ジョブを再実行しますか

データソース demo-wiki-export の失敗したジョブ job-0005-demo を、同じ指定で新しいジョブとして起動します。

引き継ぐ指定
強制削除モード: あり再書き込みモード: あり

強制削除モード

  • 割合ルール・最小件数ルールを無視して削除します。TTL が経過していない文書は消えません。

再書き込みモード

  • 要約を有効にしている場合は、実行前に Indexer の要約生成を止めて終えてください。
確認にチェックすると再実行できます。

指定がどちらも「なし」のときは、警告枠・確認チェックなしの「要確認・標準」(primary「再実行」)。指定は変更できない(UC-11・17)。変えたい場合はデータソースの「クロール起動」から指定する。

ロック解放(DLG-5。要確認・警告つき)— リース切れのジョブ

ロックを解放しますか

データソース demo-notes-archive のジョブ job-0004-demo は、リース期限(2026-11-19 02:10)を過ぎて止まっています。

解放すると次のようになります

  • ジョブは「失敗(ロック解放済み)」になります。
  • ジョブは再起動されません。解放後にクロールを起動し直してください。
確認にチェックすると解放できます。

解放できないとき(リース期限内の実行中・実行待ち、取得直後)は、ダイアログ内のアラートで理由と次の行動(「取消を使ってください」「しばらくしてからやり直してください」)を示す。
