## 1. 目的

Indexer が OpenSearch に対して行う書き込みの負荷と、実機でしか確かめられない挙動を測定・確認し、結果を設計書とは別にここへ記録する。数値の既定値(リトライ回数、削除バッチ件数など)は、この結果を見て決める。測定の観点と合格条件は設計書(15.4、S-13、U-31)を正とし、ここには複製しない。

## 2. 記録のルール

- 実際に測定・確認した結果だけを書く。推測や期待値を結果として書かない。
- 実施前の項目は「未実施」と書く。実施後に、日付・実施者とともに結果を書く。
- 測定ごとに、3章の項目(環境、条件)を必ず併記する。条件が違う結果を同じ表に混ぜない。
- 再測定は、上書きせず新しい行・節として追記する。
- 設計書の内容は複製せず、参照だけにする。結果が設計の変更を要する場合は、「評価」に書き、設計書側へ反映する。
