## 対応

Important(3件とも対応)
1. 320px の見切れ: アラート・ダイアログ内ボタンの折り返し、`.alert{min-width:0}`、`overflow-wrap:anywhere`、フレーム余白 16px。320px で全ダイアログのはみ出し要素なしを計測
2. ドロワー: Esc・スクリム・☰ 再押下で閉じる。上部バーの下(top:48px)から開き ☰ が覆われない。Esc 後は ☰ にフォーカス復帰。仕様書 DS 8章に反映
3. 無効の実行ボタンの理由文言+`aria-describedby`: `#dlg-delete`(「識別子を入力すると削除できます。」。一致で消す)、`#dlg-rerun`(「確認にチェックすると再実行できます。」)、DS モックのロック解放・データソース削除見本にも追加。仕様書 DS 4.8・admin-view 7.8 に反映

Suggestion
- ソートボタンのフォーカスリング: `outline-offset:-2px` で内側に描画
- 600px 未満で 44px: 並べ替えセレクト・行メニュー項目・スナックバー閉じる・DS の「ジョブ詳細」「再読み込み」。375px の両モックで 43.5px 未満の操作要素が 0 件(実測)
- outlined ボタンの枠: 既存トークン `line-strong`(`#6F7C88`、白と 4.27:1)に変更(新トークンなし。DS 2章・4.2 同期。「案」)
- 行操作ボタン: 仕様書側を修正し小型 32px を明記(表の行・ツールバー・アラート内。600px 未満は 44px)。理由: 2行行(56〜60px)の密度維持、WCAG 2.2 の 24px 以上は満たす
- 削除ジョブ実行中の行の見本(`demo-tmp-share`、「削除中」タグ+補足文+操作なし)を追加し 7 件表示、並び順を識別子昇順に修正

Nitpick(対応分)
- ダイアログ幅: 仕様書を 600〜839px は 560px 中央、600px 未満は幅いっぱいに修正(DS 7章、admin-view 7.9)
- エラー(データなし)の赤枠: 仕様書 DS 4.5 を「赤系のアイコン枠(`error-container` 面)」に修正
- `#dlg-rerun` の色ルール: 「複数の指定を含む場合は帯と実行ボタンを最も重い指定の色に合わせる(強制削除=赤 > 再書き込み・ロック解放=琥珀)。警告枠・確認チェックは指定ごと」(案)。モックの帯を赤に。DS 4.8・admin-view 6章に反映
- 「最終更新(成功)」の空白、`#line-strong` スウォッチ(白面+下端8px帯に変更)
- 対応しない: モックの見出し構造・nav 重複(並置表示の都合)、favicon 404、840px の表内スクロール(`.doc` パディング由来)
