## 新規指摘

- **S-1 Suggestion**: `jobs-v0.1.md` 1.2「レイアウト(幅 1280px)」の全列の図と、1280px の実表示(3列が補足行)が食い違う。補足行は「データソース · 種別(起動)」だけで、起動時の指定(「強制削除」「再書き込み」)タグが一覧から消える(全7列でタグが出るのは viewport 約 1300px 以上)。提案: (a) 1.2 を「全列表示(カード幅約 1000px 以上)」に直し1280px の補足行表示も添える、(b) 補足行にも起動時の指定タグを出す
- **N-1 Nitpick**: D1 の説明文が `#d1-normal` にしかない(他の状態では更新操作の縦位置が約 46px ずれる。モックの省略。実装では全状態で出す)
- **N-2 Nitpick**: 本文内リンク 24px 規則(DS 2.3 `:139`)が表のリンク(J1 のジョブ ID 15px、S1 のソース ID 15px、S2 のリンク 15〜17px、X1 のソース名 20px、J1 注記リンク 17px)に及んでいない。表の行は 48px 以上で WCAG 2.5.8 の間隔の例外が働くと考えられる。DS 2.3 の文言を「表の識別子リンクは行全体の余白で確保する」に書き換えるか、24px に揃える
