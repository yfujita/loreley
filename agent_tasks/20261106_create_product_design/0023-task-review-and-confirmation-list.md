## (d) ユーザー確認事項の一覧

### 確認済み

| 項目 | 確認の事実 |
| --- | --- |
| ブローカーなし、HTTP直接通信、Crawler / Indexer を別コンテナ、ジョブ起動もHTTP | 2026-11-08 の指示 |
| ジョブの起動と記録は Crawler(受信時にロックとジョブを保存、202 / 重複は 409) | Q1 |
| 責務:データは Indexer、ジョブは Crawler | Q2 |
| Crawler → Indexer は同期HTTPのバッチ登録(形式・上限は未決) | Q3 |
| `loreley-texts` の廃止は別の版にする | 「分ける方をお願い」 |
