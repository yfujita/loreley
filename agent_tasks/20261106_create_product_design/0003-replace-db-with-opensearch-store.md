# 0003 DBを廃止し、OpenSearchをKVSとして使うStore層に置き換え

## 実施した作業の概要

ユーザーの指示（2026-11-06）をv0.2に反映した。

- 専用のDBは置かない。まずはOpenSearchをKVSのように使い、DBの代わりにする。
- コード上はDBサービスとして扱い、バックエンドを差し替えられるようにする。

## 判断・設計上の理由

- **インターフェースの範囲**：OpenSearchで実現できる操作（IDによるCRUD、単純な一覧、seq_noを使った楽観的排他制御）に絞った。将来RDBに差し替えたときも、トランザクションやJOINに依存しないことで実装の差を小さく保てる。
- **整合性**：OpenSearchの検索はニアリアルタイムで、リフレッシュ後にしか結果に反映されない。そのため、状態の確認や排他の判定にはIDによる取得（リアルタイム）を使う方針を明記した。
- **認証情報**：KVS用インデックスに平文で残さないよう、環境変数や秘密情報ファイルで参照する方式を基本とした。
- **インデックスの分離**：検索用インデックスとKVS用インデックスを分けた。検索インデックスをエイリアスで切り替えて再構築するときに、抽出済みテキストが影響を受けないようにするためである。
