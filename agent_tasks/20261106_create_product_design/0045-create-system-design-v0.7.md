- §11 試験表: D-6、D-11、D-12、D-19、D-20、D-23、D-30、E-31 を書き換え。E-18、D-8、D-17、L-5、R-2 のPD参照も更新。D-31〜D-38 を追加(待機中のStatus表示、3世代FIFO、待機中のメンテナンス・再起動、ソース削除での停止、旧・新で別のスナップショット(`force_delete` 双方向)、待機中のポーリングタイムアウトでもロック解放、旧削除の件数照合不一致)。§11.8 を D-1〜D-38 に更新、新節 §11.12 を作成。

## grep の結果
- `interrupted`: 状態としては使っていない。残存は、改訂履歴・変更点・「v0.7で変更」の注記、過去版の記述、§11.10 の旧行、D-12 の「`interrupted` にならない」。

## 判断・留意点
- ソース削除の停止確認の「ソースの記録」は、Indexer が `loreley-sources` を読まない前提から `deletion-{source_id}` と具体化した。その結果 §1.2 の手順を変更した。これは document-writer の解釈で、案として記載。レビューで確認する。
- `failed` の理由コード名は、`maintenance`/`indexer_restart` 以外は仮置き(`outcome_failed`、`outcome_cancelled`、`delete_error`)。
- 異なるソース間の並行度、同時刻の `finish_received_at` の順序は規定せず、§12.5 に回した。
