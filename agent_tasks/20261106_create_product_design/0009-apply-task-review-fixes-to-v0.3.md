## 0008の訂正・補足

- 0008で「document-writerが補った点」を「4点」としたが、列挙は3点(`fetch_fail_count`の新設、恒久失敗文書は取得を試み続け成功すれば解除、恒久失敗文書を`pending_index`の期限削除から除く)だった。正しくは3点。ただし今回の修正で、`pending_index`の期限削除は「検索インデックスに存在しない場合に限る」が加わった。
- 0008で触れなかったv0.3レビューの低指摘6件の扱い：
  - 反映済み：用語・命名の不一致、v0.2から落ちた記述の復元、`localhost`待ち受けと社内利用の衝突、本文の実装詳細の削減、間引きの詳細(0008作成時点の修正で対応)。

- 付録の整合の全体通読は、task-reviewer で実施済み。今回の修正後の再通読は行っていない。
- 作業プロセス：個別のプラン記録とユーザー承認は取っていない。ユーザーの「レビューして、改善点があればv0.3を作成して」という指示から直接進めた(0001と同じ進め方)。task-workflow の形式からは例外であり、ユーザーに報告する。
