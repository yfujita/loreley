## 修正内容

- **#23 Origin 検査を削除**: A 5.5 を削除(5.6→5.5、5.7→5.6 に繰り上げ)。環境変数 `ALLOWED_ORIGINS`、共通 code `origin_not_allowed`、I-64 を削除。BAPI-P-15 は「不採用」の行として残す(欠番扱い)。A 2.3 に**未対応のリスク**(悪意あるページからのブラウザ経由の書き込み要求、DNS rebinding への保護がないこと。検討したがユーザー判断で不採用、認証導入時に再検討)を新設し、BAPI-U-8 に登録。B に 2.10(安全性。フェーズ1の抜けの補完)を新設。
- **#19 再実行専用 EP を削除**: 旧 EP-08(`POST /jobs/{job_id}/rerun`)と 409 `job_not_rerunnable` を外した(Admin 固有 code は 14 種)。AF-5 は EP-10(J2)と EP-06(起動)に対応。再実行は、J2 の応答(`source_id`・`force_delete`・`rewrite_mode`・`rerunnable`)をもとに画面が EP-06 を呼ぶ。`rerunnable`・`rerun_blocked_reason` は画面の出し分け用の導出フラグで、サーバー側では強制しない(表示が古くても、Crawler のロックで二重起動にならず 409 `lock_held`、通常の手動起動と同じ新しいクロールが走るだけ。B 4.1 に記載)。起動 EP のリクエストへの追加項目はなし。AAPI-P-15 は不採用の行。
- **EP-15 `/meta` は採用**: EP 番号を振り直し(旧 EP-09〜15 → EP-08〜14。欠番なし。`/meta` は EP-14)。振り直しは B の改訂履歴と 11.7 の注に記録。ID(`BAPI-P-15`・`AAPI-P-15`)は欠番として残す。
- **区分・承認日**: ゲート2で承認された項目を「承認済みの案(ゲート2。2026-11-22)」に更新(方針がゲート1で承認済みのものは「方針はゲート1、具体値・名前はゲート2」)。`-K-` は増やしていない。B 11.7 に「回答」列を追加。
