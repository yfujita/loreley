## 経緯

現行の S3・S4 の「取得設定」は、取得元のパス(`root`)だけの想定だった(設計者の取りこぼし)。Crawler の設計書・実装を確認したところ、`file_system` の `connector_config` は 5 項目(FS 設計書 `connector-file-system-v0.3.md` 2 章、承認済みの案 CFS-P-1〜4・25。実装 `apps/crawler/.../connectors/filesystem/config.py`)。

| 項目 | 型・必須 | 既定 | 内容 |
| --- | --- | --- | --- |
| `root` | string・必須 | なし | `/` で始まる絶対パス(末尾 `/` 除去。`//`・`.`/`..`・NUL 不可) |
| `include_patterns` | string[]・任意 | `[]` | 既定の拡張子(.txt .md .markdown .html .htm .pdf。固定)に**追加**で対象にする glob |
| `exclude_patterns` | string[]・任意 | `[]` | 対象から除く glob(ファイルにもディレクトリにも適用) |
| `follow_symlinks` | boolean・任意 | false | シンボリックリンクをたどる |
| `include_hidden` | boolean・任意 | false | 名前が `.` で始まるものを対象にする |

配列は 1 配列 100 件・1 パターン UTF-8 で 1〜1024 バイト(仮値・設定可能)。未知の項目は `config_invalid`。

## 設計内容(案)

- 「取得設定」カード: `root`(必須、等幅テキスト)は常に表示。「詳細な取得設定」(折りたたみ)に、`include_patterns`(ラベル「追加で対象にするパターン」。「既定の拡張子に**追加**。対象を絞る用途には使えない(絞るには除外)」と明記。既定の拡張子 6 種を読み取り専用で表示)、`exclude_patterns`(「除外するパターン」)、2 つのスイッチ(`follow_symlinks`・`include_hidden`。既定オフ。オン時の影響の警告)、glob のヘルプ(開閉式。`*`・`?`・`**`、例 `docs/**`・`**/*.draft.md`・`**/node_modules/**`、隠しファイルがオフの間は一致しても対象外・除外が優先)
- パターン一覧入力: 1 行 1 パターンの入力欄を「パターンを追加」「n 行目を削除」で増減(サーバーの項目別エラー `include_patterns[2]` を該当行に出せるため)。追加後は新しい行、削除後は次の行(なければ前の行、空なら追加ボタン)へフォーカス。入力欄で Enter は下に行を追加(空のときは何もしない)。件数「N / 100 件」、100 件で追加ボタンは `aria-disabled`+「(上限)」+通知。800 バイト超でバイト数表示、1024 バイト超でエラー。空の行はエラー(自動で除くと添字がずれるため)。ただし追加しただけで Tab 離脱したときは出さず、一度入力があった後か送信時から。重複は許容(Crawler が拒否しないため)。前後の空白は trim せず注意文。フォーカスアウト検証は入力欄だけ
- 折りたたみ: S3 は閉じて始め、S4 は既定と違う値があれば開く(すべて既定なら閉じる)、エラーがあれば開く。エラー要約のリンクは、閉じていれば開いてから該当行へフォーカス。見出し行に設定の要約
- エラー: 画面は全項目を事前検証。Crawler の固定文との対応表(2.3.2)。`root` 空は Crawler が「`/` で始まる絶対パスでない」を返す(「必須の項目がない」はキー省略時のみ)。添字なしの配列エラー(100 件超など)は一覧の下に出す。サーバーの `config_invalid` は Admin API が項目別に返す前提(案 (a) `message` の解析+fallback、案 (b) Admin API が先に同じ検証(推奨))
- S2: 5 項目すべて表示(パターンは件数と一覧、6 件以上は最初の 5 件+「ほか n 件を表示」。真偽値は「はい / いいえ(既定)」)。`connector_type` は S3 で 1 選択肢、S4 は読み取り専用(「種別によって取得設定の項目が変わります」)
- 項目定義表(2.3.1)で、Connector 追加時にこの形の表を種別ごとに足す形で拡張(8.3.1)。接続テスト・ファイルブラウザ・パターンのプレビューは置かない(提案として 4 章に分けて記載)
