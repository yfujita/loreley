## 12. リスクと対策(要約)

- 方向性・トークンが第2段階で覆る → ゲートBと軽量レビュー、部品見本に詳細・フォームを含める
- 孤児ロック(AF-7)の入口が機能設計書に無い → S2 のロック状態表示に解放導線を置く案、ゲートCで確認
- 挙動をモックで再現できない → 状態並置+ハッシュURL、挙動は仕様書記述(P-B)
- PrimeVue 実物とモックの乖離 → Aura 対応方針と標準部品で実現可能な範囲に限る、事前調査
- 未決事項を決定済みと書く → 「案」明記、ゲートC、document-reviewer 観点2
- 要件外の画面・項目の混入 → ダミーなし(前提7)、document-reviewer、task-reviewer
- 外部通信の混入 → 依頼文で禁止、Grep・ネットワーク確認
- ポート競合 → 8765等を使い自分で起動したものだけ停止
- ロールバック → 新規ファイルのみ。削除で戻せる
