## 設計内容

- O1 は 1 カード「クラスタ状態」。上部に概況(クラスタ名+状態タグ、状態の説明、件数 4 項目(ノード / アクティブ(うち移動中 n)/ 未割り当て / 初期化中)。840px 未満は 2×2)、1px の境界線の下にマトリクス領域(凡例・補足・ページ送りバー・ノード×インデックスのマトリクス。0023・0024 の確定内容は変更なし。列数の式・W・検算表も変更なし)
- 件数の定義(案): アクティブ=割り当て済みで初期化中でないシャード(移動中を含む)、移動中=アクティブの内数(OpenSearch の relocating)、未割り当て・初期化中=外数。アクティブ+初期化中+未割り当て=全シャード数(当初の「初期化中・移動中」を 1 項目とした案を、内数・外数が分からないため改めた)。全状態の値の表は opensearch 3.0 にあり、モックと一致
- 概況の高さ(1280px 実測): green 161px、yellow 183px(840〜900px の yellow は 205px、768px 以下は 223〜311px)。1280px の通常系はカード全体が約 600px で 1 画面に収まる
- 状態: 空=概況は通常+概況の下に「インデックスがありません」、読み込み中=見出し+スケルトン(カード内 `role="status"`、`aria-busy`)、エラー=見出し「クラスタ状態」を残してエラーブロック、stale=カード全体を前回の値で表示(注記は h2 の外=見出し行の右の別要素。aria-labelledby の参照先は常に「クラスタ状態」のみ)。取得は 1 つの結果(概況だけ・マトリクスだけが失敗する状態はない)。`o1-state-*` は全状態カード `o1-cluster` の中に統一
- 概況の件数ラベルは短くし(項目名に「シャード」を繰り返さない)、320〜345px・840〜900px の語中折り返し(「シャー/ド」)を解消
- 更新ボタン・最終取得日時はページ見出しの右(概況とマトリクスの両方に作用するため)。読み込み中にも更新ボタンを出す

- web-ui-reviewer: Critical・Important なし。12 状態×7 幅(320〜1280px)で横スクロール 0、列数は式どおり、概況の値とマトリクスが一致、各状態・a11y 構造に問題なし。Suggestion 2(件数ラベルの語中折り返し、stale 時の見出し名に注記が連結)・Nitpick 4(概況の高さの実測値、モックの古い記述、ランドマークの記述など)→ 反映
- document-reviewer: Critical なし、Important 5(#22 の改訂回数の食い違い、旧 #22 の 3 カードを「ユーザー指示」と読める書き方、testid の位置の不一致、件数 4 項目の合計が合わない、見出し階層・ランドマークの記述)・Suggestion・Nitpick → 反映。「項目」の解釈(カード名)の確認事項も追記
