## 設計内容(すべて案。向きとページングを除く)

- 行見出し=ノード名+「シャード n」(固定表示)、列見出し=インデックス名+状態タグ+「シャード n」。「未割り当て」は未割り当てがあるときだけ最下部の行。各セルにシャード番号のチップ(プライマリ=P 塗り、レプリカ=R 枠、未割り当て=点線+三角/八角形、初期化中/移動中=青+矢印。色・形・文字で区別)
- 1ページの列数 = `max(1, floor((W − H) ÷ 112))`(上限なし)。W=シャードの配置カードの内容領域の幅(枠 1px×2 を除く。表はカード全幅)、H=行見出し列の幅(viewport 600px 以上 152px、未満 112px)。実アプリの目安: 1280px=7、1145px=6、1024px=5、840px=3、768px=5、375px=2、320px=1
- 並び順は状態の悪い順(red→yellow→green)→名前昇順。全幅で同じ表(旧「840px 未満はブロック積み」は廃止)
- ページ送り: [前へ] [ページ n / N ▾] [次へ] と「a–b / 全 N 件のインデックス」(開始=終了は「N / 全 N 件」)。`role=status` `aria-live=polite`、端のボタンは `aria-disabled`+ハンドラでガード、600px 未満は1行・各 44px(320px で内側に収まる)。総数が1ページ以下ならページ送りを出さない(375px・320px では 3 件でも出る)
- 読み上げは「初期化中」「移動中」を分ける(見た目は同一)
