## 変更内容の要点
- **エラー名**: 終了通知の `source_id` 不一致の 409 は `finish_source_mismatch`(案)に統一(api 3.4・4.4・API-U-21、loreley-deletions 2.2、architecture P42(4))。architecture の名称記載は P42(4) の1か所に寄せ、9.5 の事前照合・K32 の行・U-4 は参照のみ。architecture の `crawl_source_mismatch` は登録の拒否(条件2)の行(9.5 の分類表、D-77)だけになった。
- **処理順**: 「形式検証(400)→ `source_id` の事前照合(409)→ 再送の判定」を architecture 9.5 と api 4.4 に明記(形式検証との前後は案。K32 で確定しているのは「処理の前に照合」まで)。内容も `source_id` も違う再送は `source_id` 違いの 409。
- **K32 の確定範囲**: ダイジェストに `source_id` を含めないのは「含めない前提(任意。K32)」の表現に統一(architecture、api の確定表・4.4・API-U-21、loreley-deletions)。
- **P42(一覧の削除タイミング)**: architecture 9.4・9.6・9.7・9.8・9.12・12章・15.6・D-93 に「(案。P42)」、15.6 は「P42(2) を採るなら」と条件を明記。別書き込みの場合・書き込み後に落ちた場合の残存した一覧は判定に使わず、保持件数 N の整理で結果ごと消える(案)。loreley-deletions 6章と api 4.4 も同じ文言に揃えた。
- **P42(1)(上限超過)**: 一覧を保存せず、超過の事実と合計件数だけを記録する(案)。記録先の項目名は未決(U-14)で、loreley-deletions のスキーマ表に1行追加。受理は 202 のまま判定時に `validation_failed`(その間 `status` は `running`)を案、受理時に判定する代替は未決と併記。上限は「architecture U-2。api では API-U-5」で相互参照を統一(loreley-deletions で誤って使っていたローカル U-5 を修正)。
- **`rewrite_mode`**: 省略・未指定・`false` の扱い(複写時に `false` に補うか省略のまま保持するか)は未決(API-U-20)。api 4.1 の「既定 `false`」を修正、loreley-deletions 4章・2.3、architecture 4.3・C-27(b)・D-94(c)(d)(正規化の方針に依存と注記)に反映。D-94(f)(真偽値以外)は期待結果未決で追加。
- **15.6(容量)**: 64文字の出典(api 3.3)、`deletion_result` は処理中に何度も更新され更新のたびに一覧を含む文書全体が書き直されること(`deleted_count` の進捗更新の頻度は未決)、一覧をマッピング上は検索対象外にする案(`enabled: false` など。U-6)を追記。
- **テスト観点**: D-91 に (m4)(未受理の `running` の結果への `source_id` 違いの初回の終了通知 → 409、状態不変、続けて正しい `source_id` は通常どおり受理)、(o)(形式不正かつ `source_id` 違い → 400)、(p)(形式が正しく `source_id` だけ違う → 409)、(q)(内容も `source_id` も違う再送 → `source_id` 違いの 409)を追加し、(k) に「読み直し後、受理した1通のダイジェストと一覧が同じ通知の内容と一致する」。D-17 に一覧が保存されない(ダイジェストは保存。案 P42(3))、D-13・D-41・D-42 に一覧が削除されダイジェストが残る(案 P42(2))。D-92 は (a)→(b) を連続した1シナリオ、(c) を別ケース、具体数(A の一覧 2 件に対し B は既存スキップ 2・新規スキップ 1・サイズ超過 1、`E_missing`=2)。(c) は上限値を設定で小さくして再現し、応答コード・検出時点・記録先は未決(案を1つ記載)。D-93 は再起動後に `loreley-deletions` を直接読んで一覧が空・B による文書の削除が 0 件、期待結果を「(1)B、(2)A」の箇条に。D-20 と D-34 の重複は D-34 に寄せた。新設 ID はなく(D-91 内の項目追加のみ)、16.1 の一覧・構成表は更新不要。
