# 0018 v0.4 外部レビューの検証と v0.5 プラン(プラン更新)

## ユーザー指示
v0.4 の外部レビュー(判断8項目への推奨と追加指摘3件)を提示し、「指摘を確認し、適切であれば改善した v0.5 を作成して」と指示。

## 方針上の注意
外部レビュアーの推奨はユーザーの承認ではない。v0.5 では、推奨を採用した記述も「案(推奨。ユーザー承認待ち)」とし、確定欄(K 系)には移さない。特に K12(ユーザー確定の文言)は書き換えず、外部の文案を P31 に「案」として併記する。プロダクト設計 v0.14 は修正しない。

## v0.5 プラン(方針。すべて案。K12・P31 の確定扱いなし)
- 対象: Indexer 5文書を v0.5 として新規ファイルで作る(v0.4 以前は変更しない)。SD・旧版・「変更点」への言及なし。プロダクト設計への言及は v0.14 の節名のみ。
- 新規/改訂 ID(architecture): P36 改訂(受理条件、終端は拒否、呼び出し種別での区別)、P37(開始通知の再送一致検証)、P38(change の unchanged)、U-29(P34 の案A/案B)、U-28 更新、U-16(url/path)は2項目の案に更新、P31 に K12 改訂文案を併記、P33 の保証表現、P35 の書き込み手順、U-21 は存続(推奨)、9.14 の Crawler 向け要件。
- 変更しない: K12 の本文、プロダクト設計。
