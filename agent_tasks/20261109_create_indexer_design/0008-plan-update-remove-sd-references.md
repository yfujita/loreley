# 0008 方針変更: v0.2 文書から SD への参照を除去する(プラン更新)

## ユーザー指示(タスク完了報告後の追加指示)
「各ドキュメントが SD を参照している箇所があるが、SD は廃止予定なので、そういった記述は一切やめてほしい。なるべく各ドキュメントで完結する記述が望ましい。」

## 方針の変更点(0001 プランの更新)
- 0001 §2 P3 の「出典注記として SD の節番号・行番号を残してよい」「変更点・出典表は残してよい」を撤回する。
- v0.2 の5文書から、SD(system-design-v0.8.md)への言及を一切除去し、各文書で完結させる。
  - 「SD v0.8」「SD は…」「SD に定めがない」「§番号」「L行番号」「(SD 由来)」などの表現を除く。
  - 「SD に定めがない/SD 未定義」は「未定義」「本書では未決」などに言い換える。
  - 確認状況の区分(確定/案/未決/推測)は本書自身の区分として定義し直す(確定=ユーザー確定、案=ユーザー未確定、推測=根拠が弱い想定)。
  - 「変更点(v0.1→v0.2)」「出典と編集方針」の章は SD 参照が前提のため v0.2 から削除する(経緯は作業記録 0002〜0008 に残す)。
- 仕様・数値・状態値は変えない。設計判断は決めず未決に残す(0001 の方針は維持)。
- v0.1(抽出版)は SD との照合のための版であり、今回の対象外とする。v0.1 の扱い(削除するか、SD 参照を除くか)はユーザーに確認する。
